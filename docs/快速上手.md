# 📖 Codex Mobile Pro — 快速上手

## 环境要求

- **Android 手机**（已安装 Termux）或 **Linux 服务器**
- **网络环境**：国内可直接访问
- **DeepSeek API Key**：前往 https://platform.deepseek.com 注册获取

---

## 一、一键安装

```bash
# 进入项目目录
cd ~/codex-mobile-pro

# 运行安装脚本
bash deploy.sh
```

安装脚本会自动完成：
- ✅ 安装基础依赖（git, curl, nodejs 等）
- ✅ 安装 Codex CLI
- ✅ 安装 mimo2codex（DeepSeek API 代理）
- ✅ 配置 API Key
- ✅ 部署 43 个预装 Skills
- ✅ 配置 Shell 快捷命令
- ✅ 创建备份脚本

---

## 二、启动使用

### 推荐方式：中文 YOLO 模式

```bash
cyo --zh
```

启动后自动：
1. 唤醒 mimo2codex 代理
2. 进入 Codex YOLO 模式
3. 内置中文提示词（自动用中文回答）

### 其他启动模式

| 命令 | 说明 |
|------|------|
| `cy` | 标准启动 |
| `cs` | 安全模式（每次操作需确认）|
| `ct` | Tmux 会话模式 |
| `codex-zh` | 直接运行中文模式 |

---

## 三、常用操作

### 查看正在运行的进程

```bash
cp-status
# 或者
ps aux | grep -E "mimo2codex|codex"
```

### 备份配置

```bash
codex-backup
```

### 恢复配置

```bash
bash ~/codex-mobile-pro/restore-codex.sh
```
