# ❓ 常见问题

## 安装相关

### Q: 安装脚本报错 "command not found"

确保 Termux 已更新：
```bash
pkg update && pkg upgrade
```

### Q: npm install 失败

尝试设置国内镜像源：
```bash
npm config set registry https://registry.npmmirror.com
```

### Q: 提示 "Permission denied"

给脚本添加执行权限：
```bash
chmod +x deploy.sh
./deploy.sh
```

## 启动相关

### Q: 启动报 "mimo2codex: command not found"

手动安装 mimo2codex：
```bash
# 确保 ~/.local/bin 在 PATH 中
export PATH="$HOME/.local/bin:$PATH"

# 或者直接使用完整路径
~/.local/bin/mimo2codex --model ds --port 8788
```

### Q: 端口 8788 被占用

修改端口：
```bash
# 杀掉旧进程
pkill -f "mimo2codex"

# 换个端口启动
mimo2codex --model ds --port 8789
```
然后修改 `~/.codex/config.toml` 中的端口号。

## API Key 相关

### Q: 没有 DeepSeek API Key

前往 https://platform.deepseek.com 注册账号 → 充值 → 创建 API Key

### Q: API Key 配置在哪？

文件位置：`~/.mimo2codex/.env`
```bash
# 编辑
nano ~/.mimo2codex/.env

# 内容格式
DS_API_KEY=sk-你的key
```

### Q: 想换别的模型？

修改 `~/.codex/config.toml` 中的 model 字段：
```toml
model = "deepseek-reasoner"  # 推理模型
# model = "deepseek-chat"    # 对话模型（默认）
```

## 使用相关

### Q: Codex 太贵了？

DeepSeek API 价格仅为 GPT 的 1/20，对话一次约 0.001-0.01 元

### Q: Skills 在哪？

```bash
ls ~/.codex/skills/
```
每个 skill 文件夹内有 SKILL.md 说明文档。

### Q: 如何更新 Codex 版本？

```bash
npm update -g @openai/codex
```

### Q: 如何卸载？

```bash
npm uninstall -g @openai/codex
rm -rf ~/.codex ~/.mimo2codex
```
