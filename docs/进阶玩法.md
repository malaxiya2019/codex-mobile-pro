# 🚀 进阶玩法

## 一、多会话管理（Tmux）

```bash
# 新建 Codex 会话
tmux new -A -s codex

# 在 Tmux 内启动
cyo --zh

# 分离会话（不中断任务）: Ctrl+B 然后按 D
# 重新连接: tmux attach -t codex
```

### 多窗口并行

```bash
# 在 Tmux 内: Ctrl+B 然后按 C 新建窗口
# 切换窗口: Ctrl+B 然后按 数字
# 窗口1: 跑 codex
# 窗口2: 编译代码
# 窗口3: 查看日志
```

## 二、自定义 Skills

### 创建自己的 Skill

```bash
mkdir -p ~/.codex/skills/my-skill
cat > ~/.codex/skills/my-skill/SKILL.md << 'EOF'
# my-skill — 我的自定义技能

## 功能描述
这个 skill 用于 ...

## 使用场景
当用户提到 ... 时调用

## 指令
...
EOF
```

下次启动 Codex 时自动加载。

## 三、使用 Ubuntu 容器（Termux）

```bash

pkg install proot-distro

# 进入 Ubuntu
proot-distro login ubuntu

# 在 Ubuntu 内安装编译工具
```

## 四、自动恢复模式

启动时自动恢复上次会话：

```bash
# 在 cyo 基础上加参数
cyo --zh --resume
```

### 添加开机自启

```bash
# Termux 可以配合 Termux:Boot
mkdir -p ~/.termux/boot/
cat > ~/.termux/boot/start-codex.sh << 'EOF'
#!/data/data/com.termux/files/usr/bin/sh
termux-wake-lock
nohup mimo2codex --model ds --port 8788 > ~/mimo2codex.log 2>&1 &
EOF
chmod +x ~/.termux/boot/start-codex.sh
```

## 七、性能优化

### Termux 下

```bash
# 限制内存使用（如 512MB）
export NODE_OPTIONS="--max-old-space-size=512"

# 使用后台运行
nohup cyo --zh &
```

### Linux 服务器

```bash
# 使用 systemd 管理
sudo cat > /etc/systemd/system/codex.service << 'EOF'
[Unit]
Description=Codex AI Assistant
After=network.target

[Service]
Type=simple
User=youruser
Environment="DEEPSEEK_API_KEY=sk-xxx"
ExecStart=/usr/local/bin/mimo2codex --model ds --port 8788
Restart=always

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl enable codex
sudo systemctl start codex
```
